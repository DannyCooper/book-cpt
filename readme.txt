== Description ==

A WordPress Custom Post Type for books. Supports Authors, Genre and Series.

Add purchase links in the Book details panel, then insert the Purchase Links block to show a single call-to-action button with a retailer dropdown.

Authors are managed as a taxonomy so each book can have one or more authors assigned.
